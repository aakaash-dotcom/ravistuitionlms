## WHAT THIS INTEGRATION DOES

When a student scans their fingerprint on the XS200 device:
- **Entry punch (1st punch)** → WhatsApp to parent: "Your child [name] has entered the centre at [time]"
- **Exit punch (2nd punch)** → WhatsApp to parent: "Today's attendance: Present ✅ — Entry: [time], Exit: [time]"
- **No punch at all** → At 9 PM (evening class) or 9 AM (morning class), WhatsApp to parent: "Today's attendance: Absent ❌"

Admin can also register students in jiSECURE directly from the app, and view/manage biometric devices.

### STEP 2: Deploy the 3 Supabase Edge Functions

Deploy these Edge Functions from the repo:

1. **`biometric-webhook`** from `supabase/functions/biometric-webhook/index.ts`
   - This receives real-time punch events from jiSECURE via webhook
   - jiSECURE sends this JSON on every punch: `{ "event": "punch_log", "emp_code": "26000", "company_id": 10000, "timestamp": "2026-10-07 13:51:51" }`
   - The function looks up the student by matching `emp_code` to `roll_no` in the students table
   - First punch of the session = ENTRY → creates attendance record + sends WhatsApp
   - Second punch of the session = EXIT → updates attendance with exit time + sends WhatsApp
   - WhatsApp is sent via the existing Deropo API (same as the current whatsapp-send function)

2. **`jisecure-sync`** from `supabase/functions/jisecure-sync/index.ts`
   - This registers students in jiSECURE SmartOffice via their REST API
   - Uses `POST https://xs.jisecure.com/api/employee/add` with Bearer token authentication
   - Sets `emp_code` = student's roll_no, `full_name` = student's name

3. **`absent-whatsapp-cron`** from `supabase/functions/absent-whatsapp-cron/index.ts`
   - Called by Vercel cron at 9 PM (evening) and 9 AM (morning)
   - Finds all active students with no attendance record for today's session
   - Marks them absent in the attendance table
   - Sends WhatsApp to parent: "Today's attendance: Absent ❌"

Deploy command for each:
